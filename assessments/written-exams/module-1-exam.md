# Module 1 Written Exam — Why MCP Exists

Covers: Chapter 1 (The Integration Problem MCP Solves)

No open resources needed beyond the chapter itself. Write full sentences
— a bullet list of keywords doesn't demonstrate understanding.

## Concept Questions

1. In your own words, explain the N×M integration problem. Use a
   concrete example with actual numbers, not just the formula.
2. What does MCP actually standardize? Be precise — this is not the same
   question as "what does MCP do."
3. Name two things MCP does **not** solve, and explain why each is a
   separate concern from what MCP standardizes.

## Scenario Questions

4. A five-person startup has one AI feature and no plans to add a
   second one in the next year. Should they build their tool integration
   as an MCP server or a plain function? Justify your answer using the
   chapter's reuse-based reasoning, not a general rule.
5. A platform team has rewritten the same internal tool integration
   three times for three different consumers. What's your recommendation,
   and what would you want to know before finalizing it?

## Debugging / Judgment Questions

6. A colleague says: "we standardized our tools behind MCP, so our
   security posture improved." Is this claim accurate? Explain what did
   and didn't change from a security standpoint.
7. Your team calculates "N+M integrations instead of N×M" and presents
   this as the total cost savings of an MCP migration. What is this
   calculation missing?

## Architecture / Production Questions

8. Design a one-paragraph pitch (like the memo project) for migrating
   3 out of 12 bespoke tool integrations to MCP servers at a mid-size
   company. Include your ranking criterion and one explicit risk your
   pitch does not address.
