Roadmap

The course mirrors the Python for Everyone / RAG for Everyone architecture: chapters grouped into modules, each ending with exercises, a practice bank, interview prep, a project, and a builder thought-process journal. Built on the finalized MCP specification 2026-07-28.

Start with Chapter 1 (live now)

Module 1: Why MCP Exists

The integration problem MCP solves before naming the protocol.

Outcome: explain why bespoke tool integrations don't scale.

Module 2: MCP Core Concepts

Host, client, server, JSON-RPC, stateless request/response, capability negotiation.

Outcome: diagram an MCP interaction end to end.

Module 3: Building MCP Servers

Tools, resources, prompts, and both standard transports with the Python SDK.

Outcome: ship a working server exposing all three primitives.

Module 4: Building Clients & Hosts

Connecting an agent to one or many servers, merging tool catalogs.

Outcome: build a host that talks to multiple servers.

Module 5: Security & Trust Boundaries

Permission scoping, sandboxing, and prompt injection via tool output — this course's core differentiator.

Outcome: scope permissions and defend against untrusted tool results.

Module 6: Production MCP

Testing, debugging, observability, versioning, and spec-compatibility hardening.

Outcome: operate a server that survives production, not just a demo.

Module 7: Architecture & Capstone

Design secure, multi-tenant MCP infrastructure for a regulated enterprise, with full ADRs.

Outcome: think and design like an architect, not just a builder.

Every Chapter Includes

Lesson, quiz, exercises, practice bank, interview prep, project, and a builder thought-process journal — every code example tested against the real SDK.

Outcome: learn like a responsible AI-era builder.
