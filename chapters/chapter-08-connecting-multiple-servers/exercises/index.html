Chapter 8 Exercises ~25 min

Exercises: Connecting Multiple Servers to One Agent

Reproduce the collision yourself, then implement the namespacing fix and a test that would catch it automatically.

How to run these 
pip install "mcp[cli]"
cd chapters/chapter-08-connecting-multiple-servers/exercises
python solution.py   # or fill starter.py first
starter.py solution.py (reference)

1 Implement the namespaced merge

Complete namespaced_merge per TODO 1. Confirm both servers' search tools survive.

2 Implement routing

Complete call_namespaced per TODO 2 and confirm calling notes-service.search and docs-service.search route to the correct, different implementations.

3 (Production-gear) Implement the collision test

Complete assert_no_collisions per TODO 3. Confirm it raises against the two colliding servers, then add a third server with a uniquely-named tool and confirm it passes for that pair.

4 (Production-gear) Add a third server, no collision

Add a third minimal server with a tool named get_weather (no collision with the other two). Extend your namespaced merge to handle three servers instead of two.

5 (Production-gear) Detect a *new* collision

Add a fourth server that also exposes get_weather, colliding with the server from Task 4. Run your collision test again — confirm it catches this new collision too, without any changes to the test itself.

6 Selective namespacing

Referencing this chapter's senior interview question 6: sketch (in comments, doesn't need to run) how you'd namespace only the colliding tools and leave uniquely-named ones with clean names.
