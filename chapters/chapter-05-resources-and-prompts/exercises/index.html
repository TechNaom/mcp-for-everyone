Chapter 5 Exercises ~25 min

Exercises: Resources & Prompts

Extend the notes server with a static resource and a prompt, then verify the discovery gotcha from the lesson yourself.

How to run these 
pip install "mcp[cli]"
cd chapters/chapter-05-resources-and-prompts/exercises
python solution.py --check-discovery   # or fill starter.py first
starter.py solution.py (reference)

1 Add a static resource

Add stats://notes returning a note-count and character-count summary, per the starter's TODO 1.

2 Add a prompt

Add summarize_note(title) per TODO 2. Remember: it returns instruction text, it doesn't fetch or process the note's actual body.

3 (Production-gear) Verify the discovery split

Run TODO 3's discovery check. Confirm stats://notes appears only under list_resources() and note://{title} appears only under list_resource_templates() — exactly the split the lesson warned about.

4 (Production-gear) Write the merge function

Write a function list_all_readable_uris(client) that calls both discovery methods and returns one combined list. This is the one-line fix the lesson's production scenario needed.

5 Tool, resource, or prompt?

For each of the following, name the right primitive and justify it in one sentence: (a) "delete a note," (b) "the server's current software version," (c) "a template asking the model to translate text to French."

6 (Production-gear) Scale the resource design

Your notes server needs to support 10,000 notes. Would you keep note://{title} as-is, or redesign it? Justify your answer using the scale trade-off from this chapter's interview questions.
